Buyer Reports Windows 執行檔使用說明

一、資料整理規則與前置條件

DPS：
1. 檔名需包含 DPS 字眼；程式會依活頁簿順序抓第一張名稱包含 DPS 的工作表作為來源。
2. 表頭列需包含：Line、W/O，以及 buyer_reports.ini 內設定的其中一個 DPS 料號欄別名。
3. 日期欄必須是 Excel 日期格式；若日期是用公式累加產生也可以，但檔案需經 Excel 計算並儲存，讓程式讀得到日期值。
4. 正常格式下，每個日期應該有兩欄，也就是 D / N 兩班。程式預設會把同一天的欄位加總。
5. 料號欄預設可使用 AVTC P/N、P/N 或 Model。
6. 料號結尾帶 * 的資料預設會被排除。
7. AVTC DPS 維持原本邏輯：取第一份格式正確的檔案。
8. RAKEN DPS 會合併 RAKEN 資料夾內所有格式正確的 DPS 檔，同料號同日期累加。

PP：
1. 檔名需包含 PP 字眼。
2. 程式會依活頁簿順序抓第一張名稱包含 PP 或 Data 且含樞紐分析表的工作表，作為欄位版面與客戶排序來源。
3. 該樞紐分析表對應的 pivot cache 內必須有 Plan、Customer、Model，並有名稱包含 Part Number 的料號欄位。
4. Plan 欄位的值預設必須是 Production Input，程式才會納入計算。
5. 週別與月份欄位需符合 Excel 樞紐表 / pivot cache 的格式。
6. 跨月但同週的項目會合併加總，例如 WK36 和 WK36 Sep 會寫進同一個 WK36。
7. 程式會抓 pivot cache 的更新日所在週再減一，作為可見版面起始週。例如更新日是 2026-07-31，屬於第 31 週，所以可見版面會從 WK30 開始銜接。
8. 起始週以前、同年度的 WK 週欄會從 pivot cache 補齊輸出，即使來源樞紐欄位清單未勾選也會顯示在整理後檔案中，但不納入 total。
9. 來源樞紐報表中被隱藏的時間欄位也會納入計算，並在整理後檔案中顯示出來。
10. 沒有週明細的月份會直接以月份欄位作為輸出。

DPS+PP：
1. 同一個客戶資料夾內 DPS 與 PP 都能成功讀取時，會額外產出 DPS+PP.xlsx。
2. 週別採 buyer week：週六到週五。例如 2026-08-08 到 2026-08-14 是 WK33。
3. AVTC 預設 DPS 保留到目前 buyer week + 5 週；例如目前 WK33，DPS 到 WK38，PP 從 WK39 開始。
4. RAKEN 預設 DPS 保留到目前 buyer week + 3 週；例如目前 WK33，DPS 到 WK36，PP 從 WK37 開始。
5. DPS 若在 PP 接續週含之後仍有數字，會併入 DPS 保留週的最後一天。
6. 若來源檔內有 BOM1 工作表，程式會用 BOM1 的 B 欄料號對應 H 欄 vendor 寫入 BOM；若沒有，BOM 欄留空。

二、資料夾結構

請保持整個 BuyerReports 資料夾放在一起，不要只單獨移動 exe。

BuyerReports/
  BuyerReports.exe
  _internal/
  buyer_reports.ini
  input/
    AVTC/
    RAKEN/
  output/
    AVTC/
    RAKEN/
  Windows執行檔(exe)使用說明.txt

注意：輸入資料夾名稱是 input，請不要改名。
注意：AVTC 檔案請放 input/AVTC，RAKEN 檔案請放 input/RAKEN。
注意：buyer_reports.ini 是 sheet / 欄位偵測關鍵字設定，請和 BuyerReports.exe 放在同一層。
注意：如果收到的是 zip 壓縮檔，請先完整解壓縮，不要在壓縮檔視窗內直接雙擊 BuyerReports.exe。

三、使用步驟

1. 如果收到的是 zip 壓縮檔，請先按右鍵選擇「全部解壓縮」。

2. 進入解壓後的 BuyerReports 資料夾。

3. 把 DPS 與 PP 來源 Excel 檔放進對應資料夾。
   - AVTC 檔案放進 input/AVTC
   - RAKEN 檔案放進 input/RAKEN
   - DPS 檔名需包含 DPS
   - PP 檔名需包含 PP

4. 關閉已開啟的輸出檔，避免 Excel 鎖住檔案。

5. 雙擊 BuyerReports.exe。
   若 Windows 顯示 SmartScreen 警告，請確認檔案來源可信後，點「更多資訊」再點「仍要執行」。
   執行時會顯示階段式進度條。

6. 執行完成後，到對應 output 資料夾取得：
   - output/AVTC/DPS整理後.xlsx
   - output/AVTC/PP整理後.xlsx
   - output/AVTC/DPS+PP.xlsx
   - output/RAKEN/DPS整理後.xlsx
   - output/RAKEN/PP整理後.xlsx
   - output/RAKEN/DPS+PP.xlsx
   實際會產出哪些檔案，取決於該客戶資料夾內是否有對應來源檔。

7. 每次執行都會在對應的客戶 output 資料夾產生 log，例如 output/RAKEN/log。
   如果某一種報表格式錯誤，工具會略過該報表並繼續嘗試另一種報表。
   若有報表未產出，請把 log 交給維護者確認原因。

四、偵測關鍵字設定

BuyerReports.exe 會讀取同層的 buyer_reports.ini。
預設內容如下：

[sheet_detection]
dps_sheet_keywords = DPS
pp_sheet_keywords = PP, Data

[dps]
part_number_headers = AVTC P/N, P/N, Model

[pp]
part_number_field_keywords = Part Number

[customers]
names = AVTC, RAKEN

[customer.AVTC]
dps_mode = first_valid
pp_mode = first_valid
dps_pp_dps_weeks_ahead = 5

[customer.RAKEN]
dps_mode = merge_all
pp_mode = first_valid
dps_pp_dps_weeks_ahead = 3

若未來 PP 的樞紐分析表 sheet 改成其他命名，例如 Pivot，可改成：

[sheet_detection]
pp_sheet_keywords = PP, Data, Pivot

若未來 DPS 料號欄有新表頭，例如 Buyer P/N，可改成：

[dps]
part_number_headers = AVTC P/N, P/N, Model, Buyer P/N

多個關鍵字請用逗號分隔。修改 buyer_reports.ini 後重新雙擊 BuyerReports.exe 即可，不需要重新 build。
dps_mode = first_valid 代表取第一份格式正確的 DPS。
dps_mode = merge_all 代表合併該客戶資料夾內所有格式正確的 DPS。
dps_pp_dps_weeks_ahead 代表 DPS+PP 中 DPS 要保留到目前 buyer week 往後幾週。

輸出檔的標題與料號欄會以文字格式寫入；數量欄與 total 會以數值格式寫入。total 由程式先計算好，不使用 Excel 公式。PP 的 total 只從起始週開始累加，欄名會寫出起算欄，例如 total(WK31起)。DPS+PP 的 total 會加總整份 DPS+PP 期間欄。

五、常見問題

1. 找不到 DPS 或 PP 檔案
   請確認檔案已放在 input/AVTC 或 input/RAKEN，且檔名包含 DPS 或 PP。

2. Windows 顯示「無法訪問指定設備、路徑或文件」
   請確認不是在 zip 壓縮檔視窗內直接執行。請先完整解壓縮，再到解壓後的 BuyerReports 資料夾內執行。

3. Microsoft Defender SmartScreen 阻擋
   請確認檔案來源可信後，點「更多資訊」再點「仍要執行」。
   也可以對 BuyerReports.exe 按右鍵，進入「內容」，若看到「解除封鎖」請勾選後套用。

4. 找不到符合規則的 DPS 或 PP 工作表
   DPS 請確認至少有一張工作表名稱包含 DPS，且內含 Line、W/O、INI 內任一 DPS 料號欄別名與日期欄。
   PP 請確認至少有一張工作表名稱包含 buyer_reports.ini 內的 PP 關鍵字，且該工作表內有樞紐分析表。

5. 只有其中一份報表產出
   代表另一份來源檔可能格式不符。請查看對應客戶 output 資料夾內的 log。
   若 output 內已有同名整理後檔案，可能是前次執行留下的舊檔，請以 log 的本次摘要為準。

6. 無法寫入 output
   請確認輸出檔沒有被 Excel 開著，或整個資料夾沒有被設為唯讀。

7. PP 數字看起來不是最新
   本工具讀取 PP 檔案內的樞紐快取。若提供者交檔前沒有 refresh 樞紐分析表，
   工具讀到的可能是舊快取。

8. 只有原始資料、沒有人工整理後工作表
   工具仍可產出報表；只是樣式會改用內建基本版面。
